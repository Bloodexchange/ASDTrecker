# ASDTrecker 1.2 · Liquid Glass

Тёмный трекер личных финансов для Android и браузера. Доходы, расходы, бюджеты, накопления, анимированный 3D-фон, аналитика и личный аккаунт.

- **Веб-приложение:** https://asdtrecker.vercel.app
- **APK:** [GitHub Releases](https://github.com/Bloodexchange/ASDTrecker/releases)
- **Настройка сервисов:** [SETUP.md](SETUP.md)

## Простые шаги

1. Откройте сайт или установите APK на Android 8+ с актуальным Android System WebView.
2. Нажмите **A → Регистрация**, введите имя, email и пароль от 12 символов.
3. Сохраните пароль: письма для восстановления пока не подключены.
4. Добавьте счёт и начальный остаток, затем доходы и расходы. Для траты обязательны категория и пояснение.
5. Дождитесь **«Сохранено в Neon»**. На другом устройстве войдите в тот же аккаунт.
6. Откройте **«Курсы и изменения»** внизу страницы или в настройках, чтобы посмотреть курс, дату и изменение в процентах.

Вход открывает отдельные данные аккаунта. Старые записи без аккаунта не переносятся автоматически. Для переноса: без входа создайте резервную копию → войдите → восстановите копию. Восстановление заменяет данные аккаунта после подтверждения.

Если два устройства изменили данные одновременно, приложение остановит запись и предложит выбрать версию. Перед выбором сохраните резервную копию. Несохранённые изменения не затираются молча.

## Новое в 1.2

- Тёмный Liquid Glass: полупрозрачные панели, мягкие отражения, плавающая навигация и органический анимированный фон.
- Плавные переходы между шестью разделами, открытие/закрытие окон. Системное уменьшение движения и настройка анимаций учитываются.
- Раздел **Валюты**: конвертер, смена направления, текущие курсы, поиск валют и проценты изменения.
- Ввод **100000 сум** или **100000 UZS** в поле CNY автоматически пересчитывается в юани. Можно выбрать валюту ввода отдельно. Голое число считается в выбранной валюте; неоднозначный знак ¥ требует кода CNY или JPY.
- Предварительный результат до сохранения. Оригинальная сумма сохраняется в деталях операции; списание со счёта происходит только в учёте.
- Валютные суффиксы также поддерживаются в бюджетах, целях и начальном остатке счёта.

## Курсы — точное описание

По умолчанию работают бесплатные ежедневные [ExchangeRate-API](https://www.exchangerate-api.com/docs/free) и [ЦБ Узбекистана](https://cbu.uz/ru/arkhiv-kursov-valyut/). Это не биржевой поток. Приложение проверяет сервер каждые 5 минут, сервер — источник раз в час.

Подготовлен серверный адаптер [CurrencyAPI](https://currencyapi.com/docs/latest/): 60, 900, 3600 или 86400 секунд в зависимости от тарифа. Без ключа он не активируется. Минутная проверка не превращает ежедневный тариф в минутные данные. Платные подписки не оформлялись.

- Для ЦБ: изменение относительно предыдущего официального курса на единицу валюты.
- CurrencyAPI: сравнение с закрытием предыдущего дня, когда источник передаёт базу; иначе — два последних полученных снимка.
- Для валютной пары пересчитываются обе валюты на текущую и предыдущую даты. Процент = (текущий / предыдущий − 1) × 100.
- Смена поставщика сбрасывает несопоставимые проценты. Отсутствующие данные показаны как «—».
- Время котировки, проверки источника и получения приложением показаны отдельно. При сбое — пометка сохранённых/резервных данных. Курсы банков могут отличаться.
- Открытая таблица обновляется автоматически. Поиск по коду — по всем полученным валютам. Конвертер поддерживает все валюты, для которых есть курс; без курса показывает понятную ошибку.
- Ключ остаётся на сервере. Общий кэш и транзакционная блокировка Neon ограничивают повторные запросы. Финансовые записи поставщикам курсов не передаются.

Курс записи фиксирует эквивалент USD на момент ввода. Обновление курса не меняет исходную сумму и проводку счёта. Для старой операции можно задать ручной курс. Сводка в другой валюте использует последний курс выбранной валюты.

## Банки

Автоподключения к балансам банков нет. Agrobank/Uzum и остальные банки — **ручные счета**, это подписано в интерфейсе. Баланс = начальный остаток + записанные доходы − расходы. Цели не перемещают деньги.

Переводов, оплаты и платёжных API нет. Номер карты, CVV, банковский PIN, пароли и SMS-коды не нужны.

## Защита и архитектура

| Часть | Реализация |
|---|---|
| Веб/API | Vercel, статический интерфейс + Node.js API |
| Пользователи/сессии | Better Auth, Neon Postgres; библиотечное хеширование паролей |
| Веб-сессия | HttpOnly, Secure, SameSite cookie |
| Финансовые данные Neon | AES-256-GCM, производный ключ владельца, user ID в AAD |
| Доступ | Владелец только из серверной сессии; параметризованный SQL |
| Конфликты | Атомарная проверка revision; устаревшая запись — HTTP 409 |
| Запросы | Origin, валидация, лимит размера и частоты в базе |
| Android | AES-256-GCM, Keystore, раздельные файлы аккаунтов; cookie зашифрована и не доступна JavaScript |
| Блокировка Android | Системный PIN/пароль при возврате, если настроена блокировка телефона |
| Экран Android | FLAG_SECURE, скрытие сторонних оверлеев на поддерживаемых версиях |
| Копия `.asdt` | AES-256-GCM + PBKDF2-SHA256, 310 000 итераций, отдельный пароль |

Серверное шифрование **не сквозное**: сервер с ключом может прочитать записи. Ключ находится в серверной переменной Vercel и не включается в веб-ресурсы/APK. Веб-копия хранится в localStorage; на общем компьютере выходите из аккаунта. Выход удаляет локальную копию аккаунта, облачная остаётся. Для выхода сначала синхронизируйте изменения.

Подтверждение email и восстановление пароля по почте не подключены. Смена пароля требует текущий пароль. Независимого аудита не было. Нативный запуск, Keystore и системная блокировка на физическом телефоне пока не проверены: устройство не подключено.

## Разработка

Требуется Node.js 24. Переменные сервера — в `.env.local`, имена — в `.env.example`. Секреты нельзя помещать в репозиторий.

```powershell
npm ci
npm test
npm run build
```

Только локальный интерфейс: `npm run dev`. Для аккаунтов после настройки Neon/Vercel:

```powershell
vercel project inspect --non-interactive
vercel env pull .env.local --yes
npm run db:migrate
$env:BETTER_AUTH_URL = 'http://127.0.0.1:4179'
npm run dev:cloud
```

В другом терминале: `npm run test:cloud` и `npm run test:cloud-ui`. Тесты создают свои аккаунты `example.invalid`, не отправляют письма и удаляют только свои аккаунты.

Не меняйте `DATA_ENCRYPTION_KEY` без перешифрования. Production-секреты могут не выгружаться через `env pull`; локальная разработка использует Development. В этой персональной установке Production/Development подключены к одной базе; перед командной разработкой выделите отдельную Neon-ветку и ключи.

## Выпуск

```powershell
vercel project inspect --non-interactive
vercel deploy --prod --skip-domain
vercel curl /api/health --deployment <проверяемый-адрес>
vercel promote <проверенный-адрес>
npm run build:android
```

Для Android: JDK 17, SDK platform 35, Build Tools 35.0.0. Путь задают `ASD_TOOLS`, `JAVA_HOME`, `ANDROID_HOME`. В текущей среде инструменты — `C:\Users\Public\ASDTreckerTools`.

Ключ подписи находится вне проекта: `%LOCALAPPDATA%\ASDTreckerSigning`. Сохраните его для обновлений. APK 1.1 подписан тем же ключом, что 1.0; прежние локальные записи остаются в режиме без аккаунта.

Репозиторий не содержит `.env`, ключей, локальных баз и пользовательских записей. APK публикуется отдельно в Releases. Результаты проверок — [VERIFICATION.md](VERIFICATION.md).
