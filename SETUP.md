# Настройка простыми шагами

## Что автоматизировано

1. Vercel CLI использовал существующий вход и создал отдельный проект `asdtrecker`.
2. Через `vercel integration add neon` создана `asdtrecker-db` на бесплатном плане. Отдельный вход в Neon CLI не понадобился.
3. Скрипт создал ключ авторизации и ключ шифрования и передал их в Vercel через stdin без вывода значений в журнал.
4. Миграция создала пользователей, сессии, ограничения запросов, финансовые копии и кэш публичных курсов.
5. Тесты проверили настоящую Neon, изоляцию аккаунтов, конфликты и пользовательский путь в браузере.
6. Vercel CLI собирает веб/API, Android-сборка содержит только публичный адрес сервера.
7. С разрешения владельца GitHub CLI публикует исходники в публичном репозитории. Управление Firefox в рабочей сессии было недоступно.

## Что сделать пользователю

1. Открыть https://asdtrecker.vercel.app.
2. Нажать **A → Регистрация**, задать имя, email и пароль.
3. Добавить записи и дождаться **«Сохранено в Neon»**.
4. Установить APK из GitHub Releases и войти в тот же аккаунт.
5. Старые локальные записи перенести через резервную копию, если это нужно. Восстановление заменяет текущие данные аккаунта.

## Если разворачиваете свою копию

```powershell
npm ci
npx vercel login
npx vercel teams ls
npx vercel projects ls
npx vercel link --yes --project <имя-проекта> --scope <команда>
npx vercel project inspect --non-interactive
npx vercel integration add neon --name <имя-базы> --billing-plan free_v3 --environment production --environment development
```

Создайте серверные переменные: `BETTER_AUTH_SECRET` — случайная строка от 32 символов; `DATA_ENCRYPTION_KEY` — 32 случайных байта в hex (64 символа); `BETTER_AUTH_URL` — основной HTTPS-адрес. Используйте `vercel env add` и stdin. Не вставляйте секреты в командные аргументы, чат или публичные файлы.

`scripts/configure-cloud.mjs` предназначен для исходного ASDTrecker. Для форка измените адрес и проверьте привязку Vercel. Скрипт сохраняет ключи в игнорируемой `.cloud`; сохраните ключ шифрования отдельно в безопасном месте.

```powershell
npx vercel env pull .env.local --yes
npm run db:migrate
npm test
npm run build
npx vercel deploy --prod --skip-domain
npx vercel curl /api/health --deployment <выданный-адрес>
npx vercel promote <проверенный-адрес>
```

Для своего APK укажите собственный HTTPS-адрес в `android/app/src/main/res/values/cloud.xml` и используйте собственный ключ подписи.

## Конвертер и ввод в другой валюте

1. Откройте раздел **Валюты** в нижней панели.
2. Введите сумму, выберите исходную и нужную валюту. Результат появляется сразу. Кнопка со стрелками меняет направление.
3. Для расхода: укажите сумму и «Ввожу сумму в», затем «Сохранить запись в». Можно просто написать **100000 сум** при выбранной записи в CNY.
4. Проверьте блок пересчёта и учётное изменение счёта, заполните назначение и сохраните.
5. В «Все курсы» ищите валюту по коду — USD, CNY, UZS, TRY и другим. У котировок указаны дата и проценты сравнения.

## Внутридневные курсы

По умолчанию опубликованный сайт использует бесплатные ежедневные курсы. Адаптер CurrencyAPI готов; ключ владельца не предоставлен.

1. Если нужны обновления внутри дня, создайте ключ в своём аккаунте [CurrencyAPI](https://app.currencyapi.com/). Выберите подходящую частоту по [тарифу](https://currencyapi.com/pricing/). Подписка не оформляется автоматически.
2. В PowerShell из папки проекта выполните:

```powershell
npm.cmd run configure:rates
```

3. Выберите интервал вашего тарифа: 60 секунд, 900 (15 минут), 3600 (час), 86400 (сутки). Вставьте ключ в скрытый запрос терминала. В чат его не отправляйте.
4. Скрипт проверит ключ, передаст его через stdin в Vercel CLI как production Secret, задаст интервал и развернёт сервер. Ключ не записывается в файлы проекта или APK. После завершения откройте «Все курсы» и проверьте фактическое время котировки.

Скрипт настроен для этого компьютера и исходного ASDTrecker. Для другого компьютера задайте VERCEL_CLI_PATH — путь к vercel/dist/vc.js. Если требуется авторизация, выполните vercel login.

Серверные переменные: CURRENCYAPI_KEY и CURRENCYAPI_INTERVAL_SECONDS. Реальный минутный источник требует собственного ключа; код адаптера проверяется контролируемыми ответами и тестами кэша Neon.
