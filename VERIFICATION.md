# Проверка ASDTrecker 1.1

## Обновление с аккаунтами

- 9 тестов расчётов, шифрования копий, валидации и процентного изменения курсов — пройдены.
- Интеграционные тесты на настоящей Neon: регистрация двух пользователей, cookie-сессия, запрет чужого доступа, атомарный конфликт версий (409), Origin (403), неавторизованный запрос (401), серверный шифротекст, смена пароля, выход и повторный вход — пройдены.
- Мобильный сценарий Chromium: регистрация, запись расхода, сохранение в Neon, перезагрузка, выход с очисткой локальной копии, повторный вход и восстановление, загруженные котировки ЦБ/мировых валют — пройден. JS-ошибок и горизонтального переполнения нет.
- На развёрнутом Vercel API: регистрация, Secure cookie, запись/чтение Neon, выход и отказ без сессии — пройдены. Проверки защищённого адреса выполнялись через `vercel curl`, это не тест публичности основного адреса.
- Реальные источники вернули 166 мировых валют и 74 официальные котировки ЦБ Узбекистана. Источники ежедневные, внутридневной поток не подключён.
- Исправлена гонка между выходом из аккаунта и фоновой синхронизацией. Исправлено чтение пустой зашифрованной cookie Android после выхода.
- Перед публикацией проверяются отслеживаемые файлы на секреты из локальной конфигурации, строки подключения, приватные ключи и исключённые пути.
- APK 1.1 собирается и подписывается тем же ключом, что 1.0. Нативный запуск и Android Keystore на устройстве остаются непроверенными.
- Тестовые аккаунты удалены по точным идентификаторам/адресам, созданным тестами. Пользовательские аккаунты не изменялись.

## История проверок версии 1.0

Дата: 14 ноября 2026, часовой пояс пользователя Asia/Tashkent.

Проверяемый путь: пользователь вводит финансовую запись → запись сохраняется → баланс и аналитика пересчитываются → данные экспортируются в зашифрованную копию → копия восстанавливается.

| Граница | Результат | Подтверждение |
|---|---|---|
| Расчёты | Пройдено | Целочисленные суммы, точность UZS/JPY/KWD, валютный пересчёт и пропущенные курсы, проводка по счёту, границы периодов |
| Интерфейс → сохранение | Пройдено в Chromium | Создание, изменение, удаление, перезагрузка и сохранность записей; тестовый профиль браузера |
| Сохранение → сводка | Пройдено в Chromium | Счета, бюджеты и накопления, навигация по пяти разделам |
| Резервная копия | Пройдено | Формирование шифротекста через форму, восстановление, отказ при неверном пароле/повреждении; выбор файла Android требует проверки на устройстве |
| Ввод офлайн | Пройдено в Chromium | Новая операция при отключённой сети |
| Демо | Пройдено | Демонстрационные данные не изменили сохранённые записи |
| Мобильная/настольная вёрстка | Пройдено | 390×844 и 1440×1050; скриншоты; нет горизонтального переполнения и JS-ошибок |
| Интернет-курсы | Пройдено | Реальный запрос: result=success, base_code=USD, курс UZS присутствует. Сквозные тесты используют фиксированный ответ для воспроизводимости |
| APK | Пройдено | Компиляция Java/D8, упаковка, zipalign, подпись RSA-3072, проверка APK Signature Scheme v2 и v3 |
| Android на устройстве | Не проверено | `adb devices` не обнаружил подключённых устройств; эмулятор не установлен |
| Банковские API | Не подключены | Только ручные счета; нет перевода средств или скрытой имитации банковского баланса |

Защита Android реализована в исходниках и прошла компиляцию, но это не заменяет тестирование Keystore, жизненного цикла блокировки и системного выбора файлов на физическом телефоне. Независимый аудит не проводился.

При первой сборке исправлены особенности aapt2 с кириллицей в путях и компиляция Java-лямбд для Android. По результатам проверки снижено разрешение WebGL-рендера и ограничена частота до ~15 fps, чтобы уменьшить нагрузку фоновой анимации. При reduced motion остаётся статичный кадр.
